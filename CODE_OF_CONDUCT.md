# Code of conduct

unfold welcomes everyone who wants to help people learn. This code adapts the Contributor Covenant, version 2.1.

## What we ask

Please do these things:

- Be kind and patient, and assume good intent.
- Give feedback on the work, not on the person.
- Accept correction, and correct others gently.
- Credit the people and sources whose work you use.

Please never do these things:

- Harass, insult, or demean anyone.
- Share anyone's private information without their consent.
- Post sexual content, or content that targets a group of people.

## Where it applies

This code applies in this repository, its issues and pull requests, and any space that speaks for the project.

## Report a problem

Report a problem in private, through GitHub's private reporting. Open this repository's Security tab, choose "Report a vulnerability", and start the title with "Conduct:". Only the maintainer sees the report.

The maintainer reviews each report in confidence. The maintainer may warn a person, remove their content, or ban them from the project.
