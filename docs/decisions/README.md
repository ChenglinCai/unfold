# Decision records

A decision record is a one-page note of a hard-to-reverse decision, its reasons, and when to revisit it. Each record follows the minimal template of [MADR 4.0](https://adr.github.io/madr/), with one more section: "Revisit when".

To add a record, copy the newest one, give it the next number, and open a pull request. To change a decision, write a new record that replaces the old one, and set the old record's status to "superseded".
