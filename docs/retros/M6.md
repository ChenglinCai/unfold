# Retro: M6, episodes

M6 added a voice interface, beats timed by their clips, and a Whisper audio check. It also added subtitles, stitched episodes with title cards, a ledger, and the idea-link check. Three episodes now play: two consecutive ones from net-present-value, and one from a recording.

## What was hard

1. **Keys that would cascade.** A changed prompt or reply schema changes every saved key, so all built episodes would rebuild. Episode 2 got its ledger in an extra request block, and episode 1's request stayed the same.
2. **Linux saw what macOS hid.** CI found text that shrank too far under wider fonts, and a forked render worker that crashed. Both had passed on the Mac.
3. **A push failed in silence.** The commit script printed "pushed" after GitHub refused the push. It now stops on any failed push.
4. **Words and digits.** Whisper writes "$10,000" where the script says "ten thousand dollars". Both sides now become spoken words before the comparison.
5. **What the audience knows.** The first link check failed on "interest", which the audience line already names. Series files can now say so in a `knows` list.
