# Retro: M7, product and release

M7 made unfold something that a new user can start. It added `unfold doctor`, a review page, and a gallery that keeps private work out. It also added an MCP server with seven tools and a Claude Code plugin. A quickstart renders a bundled example on a clean Mac, and CI repeats that on every pull request.

## What was hard

1. **A renamed SDK class.** Version 2 of the MCP Python SDK renamed FastMCP to MCPServer, so the first import failed. A test now lists the server's tools.
2. **Rights that failed open.** The converge pass found that the gallery counted a series with no sources as public. Rights checks now fail closed, and a test covers both gaps.
3. **A skill that promised missing tools.** The skill told Claude to ingest sources and check audio, and the plugin offered neither. The server gained an ingest tool, and the plugin installs the audio extra.
4. **LaTeX on a clean machine.** The doctor first required LaTeX, which a fresh Mac lacks. Only equations need it, so a missing LaTeX now warns.
5. **Values that became options.** The security review found that a tool argument such as `--help` became an option. Each tool now passes `--` before its values.
6. **A hidden hook failure.** A commit stopped on a long task line, but the trimmed output looked like success. The commit gate now prints a failure line.

## Practices we tried

The plan named four practices for M7.

- **Small tool interfaces.** Each MCP tool runs one unfold command, so the server has no logic of its own to test.
- **Using the tool for real work.** The review page and the gallery ran on the six golden series, not only on test fixtures.
- **A security review.** It found two gaps, option injection and unchecked ids, and the fixes landed in this milestone.
- **Version numbers.** The plugin says 0.1.0, but no release tag exists yet. Progress item 19 asks you to decide.

## What to automate first

| Lesson | When | What to build |
|---|---|---|
| Rights rules must fail closed | Next feature | A test that feeds every rights check missing and odd values |
| A skill must match its tools | Next feature | A test that every tool the skill names exists on the server |
| The plugin installs from main | First release | A release tag that the plugin's server command pins |

## Numbers

- 7 MCP tools: doctor, ingest, check, build, render, review, and evaluate.
- The quickstart: one segment with three beats, 19.9 seconds long. It renders in about 5 seconds on the Mac, and the whole CI job takes about a minute.
- 6 gaps found and fixed after the first pass: 4 by the converge pass, and 2 by the security review.
- 342 tests pass, and 9 of them render video.
